# 🌍 ESRI-Coursework
**Projects from ESRI MOOCs | GIS, Cartography, Climate Change, & Data Management**

This repository showcases selected projects completed through ESRI's series of online MOOCs (Massive Open Online Courses), with hands-on work using ArcGIS, ArcGIS Pro, ArcGIS Online, ArcGIS StoryMaps, Python, and Jupyter Notebooks. Each project reflects my progression in geospatial analysis and science communication through visual tools and interactive maps.

---

## 🛠 Tools & Platforms Used
- ArcGIS Pro  
- ArcGIS Online  
- ArcGIS StoryMaps  
- Excel  
- Python  
- Jupyter Notebooks  

---

## 📘 Summary

These courses introduced foundational and intermediate skills in geographic information systems (GIS), spatial analysis, cartographic design, and environmental storytelling. Projects spanned across topics such as:

- Climate change and sea level rise
- Urban development and planning
- Interactive dashboards and web maps
- Data cleaning and integration in geospatial tools

While the exercises followed structured curriculum formats, I customized visual outputs and reflected on how GIS supports real-world science and sustainability.

---

## 🔍 Key Learning Outcomes

- Developed and shared StoryMaps to communicate climate impact data to a general audience  
- Used ArcGIS Online to produce and analyze layered datasets for spatial relationships  
- Cleaned and imported tabular data (CSV/Excel) into geospatial environments  
- Applied cartographic principles to create visually meaningful thematic maps  
- Created and executed Python scripts in Jupyter Notebooks for GIS workflows
